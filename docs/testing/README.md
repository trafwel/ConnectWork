# Manual testing

- **`connectwork-test-run.html`**: the interactive test checklist (38 tests, M1–M7 plus Appearance). Steps, what you should see, and Pass / Fail / Skip with notes.
  - **As the team's claude.ai artifact**, results are shared between teammates and Claude can read them back ("read the test run").
  - **Opened directly from this folder in a browser**, results are saved in that browser only.
- **[`../TEST_PLAN.md`](../TEST_PLAN.md)**: the same tests as Markdown, readable on GitHub. It's generated from the `PLAN` array in the HTML file, so edit the tests there and regenerate.
