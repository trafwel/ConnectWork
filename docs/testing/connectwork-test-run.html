Connectwork Test Run

Every feature built so far (M1–M9 and Appearance), written as steps and what you should see. Mark each one Pass, Fail or Skip. Results are shared with your teammate and with Claude, so a failed test can be fixed straight from here.

Before you start
  1. Get the latest main, which has every milestone through M10: git switch main && git pull && pnpm install
  2. Start the app from the repo: pnpm dev (The server lives at localhost:8787/api/…; its root address showing “404 Not Found” is normal.)
  3. Open localhost:5173 in Chrome on the same Mac.
  4. Start from the demo: Settings (gear) → Reset demo data. Most expectations below assume the 40 demo people.
  5. For import tests you need the demo LinkedIn file: demo/Connections.csv For Snap tests, the demo roster: demo/roster.pdf.

The AI runs on Gemini’s free tier, so use the fictional demo data only. Dates in the demo are relative to today, so the exact days you see will differ from any day named here.
